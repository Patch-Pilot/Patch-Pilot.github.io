# PatchPilot website

Website for PatchPilot, a Kennesaw State University senior project exploring autonomous security testing, approved remediation, and verification in an isolated lab.

## Preview locally

Open `index.html` in a browser. The site is static and needs no installation or build step. The page and team photos work offline; external GitHub and LinkedIn links require an internet connection.

## Files

- `index.html` contains the page content and styles.
- `assets/` contains the four team portraits used by the page.

Before publishing, confirm the project wording, team roles, portraits, and public profile links with the team. Email links are intentionally omitted until each person chooses an address they want to publish.
